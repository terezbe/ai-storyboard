## מה אתה עושה עכשיו, לפי הסדר

1. **PayPal (5 דקות).** פותחים חשבון ומחברים אליו את חשבון הבנק. דרכו Stan Store ישלם לך.
2. **מייל ו-3 חשבונות אינסטגרם (בערך שעה).**
   - פותחים צ'אט חדש ב-ChatGPT ומדביקים את הפרומפט מ-`setup/gpt-prompt-accounts.md`.
   - תמונות הפרופיל כבר אצלך.
   - **עדיין לא מעלים פוסטים.**
3. **לחבר את Kolbo.**
   - נכנסים ל-https://claude.ai/customize/connectors.
   - מוסיפים את Kolbo (כתובת `https://api.kolbo.ai/mcp`) ומתחברים.
4. **לפתוח סשן חדש של Claude Code** על אותו ריפו ואותו בראנץ' (`claude/video-explanation-6b9nkr`), וכותבים לו:
   ```
   Read influencers/HANDOFF.md and do it
   ```
   הוא יבדוק כמה קרדיטים יש לך ב-Kolbo, יראה לך הערכת עלות וסרטון ניסיון אחד, ורק אחרי שתאשר יפיק את כל השאר.
5. **כשהסרטונים מגיעים:** מוסיפים כתוביות ב-CapCut (Auto captions), ואז ביום 4 מעלים לפי `<דמות>/launch-kit.md`. את הכיתוב לכל פוסט לוקחים מ-`content-plan.md`, ומדליקים "AI label".
6. **יום 5.**
   - בוחרים את הדמות המנצחת.
   - פותחים חנות לפי `SELLING-GUIDE.md` ושמים את הלינק בביו.
   - מתחילים את הגל השני.
7. **יום 6 עד 7.**
   - עונים לתגובות לפי הטבלאות ב-`launch-kit.md`.
   - ממשיכים לפרסם.
   - סופרים רווח.
