# סלייד-שואו 9:16 מתיקיית תמונות · 9:16 Photo Slideshow

הופך תיקיית תמונות לווידאו אנכי (1080x1920) עם מעברים איטיים ואמורפיים,
תנועה מתמדת בכל פריים וקטע ירח מיסטי — בנוי לסרטוני זיכרונות מטיולים.

Turns a folder of photos into a vertical (1080x1920) slideshow video with
slow amorphous transitions, constant motion, and a generated moon interlude.

---

## הרצה מהירה (Windows)

```bat
cd scripts\slideshow
run.bat "C:\Users\baazo\Downloads\drive-download-20260714T154905Z-1-001" 600
```

הפרמטר השני הוא אורך הווידאו בשניות (600 = 10 דקות). זהו — הסקריפט בודק

**התוצאה:** `scripts\slideshow\workspace\slideshow_9x16.mp4`

## מה הסקריפט עושה

### שלב 1 — `prep.py` (הכנת שקופיות)

- מיישר לפי EXIF וממיר ל-RGB
- **חיתוך מרכזי ל-9:16** — תמונה רחבה (16:9) מאבדת את הצדדים ונשאר האמצע
- מגדיל ל-1620x2880 (פי 1.5) כדי שיהיה מרווח לזום בלי איבוד חדות
- **מסנן כפילויות אמיתיות** בעזרת hash תפיסתי מודע-צבע — וריאציות צבע של
  אותה יצירה **נשארות** (הן מתמזגות זו לזו יפה), רק קבצים זהים נזרקים
- **מסדר לפי דמיון ויזואלי** (שרשרת שכן-קרוב) כך שכל תמונה זורמת לדומה לה
- **מייצר קטע ירח** — ירח מלא זוהר מעל ים לילי, משתלב בנקודת הזהב (62%)

### שלב 2 — `build.py` (רינדור)

שלושה מעברים, מקביליים, עם קאשינג:

1. **קליפ לכל שקופית** — זום איטי מתחלף (פנימה/החוצה) + סחיפה צידית,
   ובנוסף מתחלף בין שלושה טיפולי תנועה:
   - `lagfun` — שובלי אור דועכים מאזורים בהירים
   - `tmix` — מריחת הד-תנועה (9 פריימים)
   - `rgbashift` + `hue` — סטייה כרומטית ו"נשימת" גוון
   - קטע הירח מקבל פאן עולה איטי (crop-pan) והחזקה פי 2.4
2. **חיבור לצ'אנקים של 14** עם מעברי `xfade` אמורפיים באורך 2.6 שניות
   (בלור-מריחה, מורפינג פיקסלים, דיסולב, רדיאלי, זום-סמיר)
3. **חיבור סופי** + הילת זוהר רכה (bloom), וינייטה וגרעין פילם

## שינוי הגדרות

```bash
python build.py workspace 900              # 15 דקות במקום 10
python build.py workspace 600 --crf 26     # קובץ קטן יותר (ברירת מחדל 21)
python build.py workspace 600 --no-grain   # בלי גרעין פילם
python prep.py <photos> workspace --no-moon   # בלי קטע הירח
```

פרמטרים נוספים בראש `build.py`:

| משתנה | ברירת מחדל | מה זה |
|---|---|---|
| `FADE` | `2.6` | אורך המעבר בשניות — גדול יותר = חלומי יותר |
| `CHUNK` | `14` | כמה שקופיות בכל צ'אנק ביניים |
| `TRANS` | רשימה | מחזור סוגי המעברים |
| `FPS` | `30` | קצב פריימים |

**חשוב:** קבצי הביניים נשמרים ב-`workspace/clips` ו-`workspace/chunks`.
שינוי אורך הווידאו או אפקטים דורש **מחיקת שתי התיקיות האלה** לפני הרצה
חוזרת — אחרת הסקריפט ישתמש בקליפים הישנים.

## זמני ריצה

מ-~120 תמונות לווידאו של 10 דקות, על 4 ליבות: בערך **30-60 דקות**.
רוב הזמן הוא שלב 1 (קליפ לכל שקופית). על מכונה עם יותר ליבות זה מתקצר
בהתאם — הסקריפט מקביל אוטומטית ל-(מספר הליבות פחות אחת).

## פתרון תקלות

| בעיה | פתרון |
|---|---|
| `ffmpeg not found` | התקן, ואז **סגור ופתח מחדש** את הטרמינל |
| `not enough slides` | נתיב התמונות שגוי, או שאין בו קבצי jpg/png/webp |
| הווידאו לא השתנה אחרי שינוי הגדרות | מחק `workspace\clips` ו-`workspace\chunks` |
| נגמר מקום בדיסק | הביניים תופסים ~2GB ל-10 דקות; מחק אותם אחרי שהווידאו מוכן |
| הווידאו כבד מדי לשיתוף | הוסף `--crf 26` או `--crf 28` |
